API reference

Stack v1.1.0

All instance methods use a colon. Shared tables (bits, buffer, LIMITS, VERSION) live on the class and are also visible on instances through __index.

Stack.New

Stack.New(options: StackOptions?) -> Stack

Create a stack object with its own budget and weak per-thread depth table.

export type StackOptions = {
    limit: number?,
    reserve: number?,
    strategy: OverflowStrategy?, -- "defer" | "spawn" | "error"
}

Statics

Stack.VERSION : string

Currently "1.1.0".

Stack.LIMITS : { LUA_CALLS: number, C_CALLS: number, DEFER_REENTRY: number }

Published engine caps: 20000 / 200 / 10.

Configure / Config / Depth

stack:Configure(patch: StackOptions) -> Stack

Update limit, reserve, or strategy. Returns the same object for chaining. Limit must be >= 8.

stack:Config() -> StackConfig

Copy of the current { limit, reserve, strategy }.

stack:Depth(th: thread?) -> number

Tracked frames on this thread for this object. Defaults to the running thread.

stack:Remaining(th: thread?) -> number

Frames left before a bounce.

Safe / Wrap

stack:Safe(fn: (T...) -> ...any, ...: T...) -> ...any

Run fn with overflow protection. If the current thread is near the budget, bounce onto a fresh thread and return those results when yieldable.

stack:Wrap(fn: (T...) -> R...) -> (T...) -> R...

Return a function that always goes through :Safe.

Recurse / Ensure

stack:Recurse(fn: ((T...) -> R..., T...) -> R...) -> (T...) -> R...

Build a recursive function. fn receives (walk, ...). Each step calls :Ensure and tracks depth.

stack:Ensure() -> ()

Checkpoint. If this thread is near the budget, yield and resume after a bounce so the Lua and C stacks reset.

Destroy

stack:Destroy() -> ()

Clears the depth table and rejects further guarded work on this object.

Writer / Reader

stack:Writer(capacity: number?) -> Writer

writer:u8 u16 u32 i8 i16 i32 f32 f64 bool varint string raw fill

All writers chain and return the writer. :len() :capacity() :reset() :finish() -> buffer :bytes() -> (buffer, number).

stack:Reader(buf: buffer, offset: number?) -> Reader

reader:u8 u16 u32 i8 i16 i32 f32 f64 bool varint string raw

Also :len() :offset() :remaining() :seek(pos) :skip(n). Reads throw on underflow.

Pack / Unpack

stack:Pack(value: any) -> buffer

stack:Unpack(buf: buffer) -> any

Supported values: nil, boolean, number, string, buffer, arrays, dictionaries, cyclic tables, Vector3, Vector2, Vector3int16, Color3, CFrame, UDim, UDim2, NumberRange, Rect, BrickColor, EnumItem, DateTime.
