A stack that refuses to overflow.

Fully typed execution and IO toolkit. One object wraps threads, tasks, signals, connections, coroutines, buffers, bit32, and binary ser/des — and bounces work onto a fresh thread before Luau can throw.

Object per budget

Each stack owns its limit, strategy, and weak per-thread depth table. Gameplay and netcode can run side by side without sharing counters.

:Safe :Recurse :Ensure

Under the VM caps

Luau allows 20,000 Lua frames, 200 C frames, and about 10 defer re-entries. Stack’s default budget is 240, then it resets the stack.

--!strict --!optimize 2

Typed and tight

Localized library calls, recycled signal runners, doubling buffer writers, and a compact tagged payload for Roblox types and cyclic tables.

local Stack = require(ReplicatedStorage.Stack)
local stack = Stack.New({
    limit = 400,
    strategy = "defer", -- "defer" | "spawn" | "error"
})

stack:Safe(function()
    walkHugeTree(root)
end)

local packed = stack:Pack({ hp = 100, pos = Vector3.new(1, 2, 3) })
local data = stack:Unpack(packed)
