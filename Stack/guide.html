Guide

Using Stack

Stack is a single Luau ModuleScript. You construct an object with Stack.New(), then call methods on that object. Two objects do not share depth counters.

Install

Drop init.luau into Studio as a ModuleScript named Stack, or map the folder with Rojo using the included default.project.json.

local Stack = require(ReplicatedStorage.Stack)
local stack = Stack.New()

Construct

Options are optional. Defaults: limit 240, reserve 8, strategy "defer".

local stack = Stack.New({
    limit = 400,
    reserve = 8,
    strategy = "defer", -- "defer" | "spawn" | "error"
})

stack:Configure({ strategy = "spawn" })
print(stack:Config().limit)

"defer" schedules the continuation at the end of the current resume. "spawn" runs it immediately on a new thread. "error" throws instead of bouncing.

Overflow protection

Luau does not eliminate tail calls. Recursion, nested pcall, and coroutine.resume chains grow the stack until the VM throws. Stack tracks frames per thread in a weak table. Near the budget it bounces the call onto a fresh thread, which resets both the Lua stack and the C stack.

-- Run any function with a bounce if this thread is hot.
local result = stack:Safe(function(n)
    return n * 2
end, 21)

-- Wrap once, call many times.
local guarded = stack:Wrap(doWork)

-- Recursion helper. First argument is the recursive function itself.
local walk = stack:Recurse(function(walk, node)
    for _, child in node.children do
        walk(child)
    end
end)
walk(root)

-- Checkpoint inside an existing recursive function.
local function visit(node)
    stack:Ensure()
    for _, child in node do
        visit(child)
    end
end

If the current frame is not yieldable (metamethod, iterator, C call) and the budget is exhausted, Stack errors rather than dropping return values — unless the work was already scheduled.

Call stack:Destroy() when the object should refuse further guarded work.

Tasks and threads

Every Spawn, Defer, Delay, and Thread starts at depth 0 on its own stack.

local th = stack:Spawn(function(name)
    print("hi", name)
end, "Ada")

stack:Defer(function()
    print("end of frame")
end)

stack:Delay(1, function()
    print("later")
end)

stack:Wait(0.1)
stack:Cancel(th)

local thread = stack:Thread(function(x)
    return x + 1
end)
local ok, value = stack:Resume(thread, 41)

Signals and bags

Signals are yield-safe linked lists. Firing reuses a runner coroutine instead of allocating one per listener unless a listener yields.

local ready = stack:Signal()
local bag = stack:Bag()

local conn = bag:connect(ready, function(who)
    print(who, "is ready")
end)

ready:Once(function() end)
ready:Fire("server")

conn.Connected
conn:Disconnect()
bag:disconnect()

stack:Connect(signal, fn, bag?) works with both Stack signals and RBXScriptSignal.

Buffers

The writer doubles capacity as needed. finish() copies into an exact-size buffer so you do not send spare tail bytes.

local w = stack:Writer(32)
w:u8(7):u16(400):f32(1.5):bool(true):string("ok"):varint(999)
local buf = w:finish()

local r = stack:Reader(buf)
assert(r:u8() == 7)
assert(r:u16() == 400)

Raw library functions live on Stack.buffer and stack.buffer.

Bits

local b = stack.bits
b.set(0, 3)
b.test(8, 3)
b.u8(-1) -- 255
b.packU24(0xAABBCC)
b.byteswap(0x01020304)

Ser / des

Tagged binary format. Tables keep identity, so cycles survive a round-trip. Integers pick the smallest tag that fits.

local payload = stack:Pack({
    hp = 100,
    alive = true,
    pos = Vector3.new(1, 2, 3),
    color = Color3.fromRGB(20, 80, 200),
    cf = CFrame.new(0, 5, 0),
})
local data = stack:Unpack(payload)

Supported: nil, boolean, number, string, buffer, arrays, dictionaries, cyclic tables, Vector2/3, Vector3int16, Color3, CFrame, UDim, UDim2, NumberRange, Rect, BrickColor, EnumItem, DateTime. Unknown types error.

Engine limits

LimitValue
Lua call frames per thread20,000
C call frames per thread200
task.defer re-entrancy~10
Stack default budget240

The default is 240 on purpose. C-stack and defer re-entry die long before 20,000 Lua frames. Raise the limit only for pure-Lua recursion that never pcalls or resumes.
